## Projeto atualmente publicado

### Módulo 02 — Fundamentos de Dados: Excel, SQL e Business Intelligence

**Programa:** DIO Bootcamp Bradesco — GenAI, Dados & Cyber  
**Curso:** 2.6 — Extraindo Insights do Feedback de Clientes Bancários  
**Tipo:** Desafio criativo / material didático de treino  
**Classificação dos dados:** MATERIAL DIDÁTICO FICTÍCIO/SINTÉTICO; nenhum dado pessoal real é incluído no repositório.

Artefato principal:

- [`modulo-02/curso-2.6/desafio-criativo-feedback-clientes-bancarios.md`](modulo-02/curso-2.6/desafio-criativo-feedback-clientes-bancarios.md)

O exercício estrutura um prompt para transformar feedbacks de uma jornada fictícia de crédito digital em insights rastreáveis, com controles de privacidade, não invenção de métricas, separação entre fatos e hipóteses e recomendação de revisão humana especializada quando necessário.
